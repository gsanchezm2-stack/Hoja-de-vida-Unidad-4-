## 📌 Descripción del Proyecto
Este proyecto corresponde al desarrollo de la interfaz de usuario (Frontend) para la Hoja de Vida interactiva y la integración con la API REST desarrollada en la Unidad 3. Incluye una vista pública dinámica para visualización de perfil y un panel administrativo completo para la gestión CRUD de experiencias laborales.

## 🚀 Características Principales
- **Vista Pública (`/`):** Muestra la experiencia laboral consumida directamente desde la base de datos en MongoDB Atlas.
- **Panel Administrativo (`/admin`):** Permite crear, listar, editar y eliminar experiencias laborales en tiempo real.
- **Diseño Responsive:** Adaptado para dispositivos móviles y de escritorio.

## 🛠️ Tecnologías Utilizadas
- **Frontend:** React + Vite
- **Cliente HTTP:** Axios
- **Iconos:** Lucide React
- **Backend:** Node.js + Express (API REST Unidad 3)
- **Base de Datos:** MongoDB Atlas / MongoDB Compass
